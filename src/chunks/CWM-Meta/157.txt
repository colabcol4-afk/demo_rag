We propose HaltEval-prelim, a novel benchmark obtained by automatically translating C programs with 
 termination annotations into Python using LLaMA-3-70B via few-shot prompting. The C programs are sourced 
 from the International Competition on Software Verification (SVCOMP) and the Termination Problems 
 Database (TPDB).13 Each original problem comes with termination/non-termination annotations, which we 
 manually verify are preserved during the Python translation phase and otherwise discard. We obtained a 
 balanced dataset consisting of 115 terminating (T) and 115 non-terminating (NT) Python programs.
